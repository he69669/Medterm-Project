## 二、輸出欄位契約

至少兩個有用途的欄位；可自行加列。

| 欄位名稱 | 型別／限制 | 用途 | 畫面標籤 | 如何查原文 |
|---|---|---|---|---|
| `trip_title` | string | 給予這趟旅程一個吸引人的主題名稱 | ✈️ 旅遊主題名稱 | 檢查主題是否扣合使用者輸入的地點與偏好。 |
| `vibe_description` | string | 總結行程風格並給予貼心提醒 | 💡 行程風格與貼心提醒 | 檢查風格描述與提醒是否合理對應輸入的季節或旅遊類型。 |
| `daily_itinerary` | array of string | 條列每日行程大綱 | 📅 每日行程大綱 | 檢查天數是否與原文要求一致，且景點安排符合使用者的偏好（如：看海、吃海鮮）。 |
| `packing_essentials` | array of string | 列出建議攜帶的必備物品 | 🎒 必備物品清單 | 檢查物品是否符合該行程的需求（如：去海邊提醒帶防曬或拖鞋）。 |
